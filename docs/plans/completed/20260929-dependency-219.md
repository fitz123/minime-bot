# Update package dependencies to compatible stable releases (#219)

## Overview
Update package-owned Pi and direct dependencies to the latest compatible stable versions, preserving current provider/auth/model selection and session history. This is compatibility maintenance, not an architecture migration.

## Non-goals
- No host Node/Homebrew/global Pi updates, production configuration changes, provider/auth migration, model default changes, session migration/deletion, new MCP/codemode features, or unrelated refactors.
- No TypeScript 7 build-tool migration: its root API lacks the compiler/transpileModule interface used by scripts/build-package-artifacts.mjs; use latest compatible 6.0.3.
- Parent owns full-suite gate, PR/release/deploy, live verification and terminal delivery; do not perform those lifecycle operations.
