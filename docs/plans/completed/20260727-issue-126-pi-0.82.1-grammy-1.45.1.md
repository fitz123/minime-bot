# Plan: Upgrade package-owned Pi to 0.82.1 and grammY to 1.45.1 (#126)

## Goal

Upgrade all four package-owned `@earendil-works/pi-*` packages from exact `0.80.6` to exact `0.82.1` and grammY from exact `1.44.0` to exact `1.45.1`, preserving Minime's package-owned runtime, RPC settlement, UI fail-closed, recovery, Telegram, cron, and rollback contracts. Integrate only compatibility changes required by the new versions and prove the upstream bounded summarization retry that resolves #98 through Minime's exactly-once delivery lifecycle.

## Non-goals

- Do not adopt new providers, OAuth flows, llama.cpp management, rich messages, Bot API 10.2 product features, new TUI/UI surfaces, or standalone Pi/TCC behavior.
- Do not add a Minime-owned compaction retry; Pi 0.82.1 owns the bounded retry policy.
- Do not classify #64's reasoning-only `stopReason=length` lifecycle as fixed.
- Do not override the new 272K OpenAI GPT-5.6 context window or relax exact dependency pins.
- Do not rewrite historical plans or changelog entries that truthfully describe earlier runtime versions.
- Do not change production/private configuration in this implementation run; release, rollback rehearsal, package deployment, restart, and production verification are parent-owned post-completion work.

## Context and evidence

- Issue #126 records the operator-confirmed exact targets and one uninterrupted full-cycle authorization; linked issue #98 closes only after its incident-specific retry proof and production verification.
- Current direct and installed versions are Pi `0.80.6` and grammY `1.44.0`. `src/pi-runtime.ts`, `src/__tests__/pi-invocation.test.ts`, current README text, recovery comments/tests, and the lockfile encode those contracts.
- Pi 0.82.1's exported compaction API accepts a `RetryPolicy` and `RetryCallbacks`; its retry classifier includes `WebSocket error`/closed transport failures while quota, abort, and exhausted retries remain terminal.
- New RPC lifecycle records are `summarization_retry_scheduled`, `summarization_retry_attempt_start`, and `summarization_retry_finished`. `readPiStream` already refreshes activity for every valid JSON record, but explicit regression coverage is required so these records remain nonterminal and cannot duplicate delivery.
- Pi 0.82.1 removes extension access to `modelRegistry.authStorage`. Supported extension-facing methods include `isUsingOAuth`, `getProviderAuth`, and `getApiKeyAndHeaders`. `src/pi-extensions/codex-web-search.ts` must keep OAuth-only refreshed-token and account-ID validation through supported APIs without exposing credentials.
- Pi 0.82.1 clamps Codex prompt-cache/session request identity before provider transport. Keep Minime's standard-session length defense unless tests prove every recovery/rollback reason for removing it; update only current-version comments.
- The private active config/settings audit found no `compat.sendSessionIdHeader`, `authStorage`, or removed model-refresh option. GPT-5.6's upstream OpenAI catalog now reports 272K context, so earlier compaction is expected and must not be silently overridden.
- grammY 1.45.1 includes `@grammyjs/types` 4.0.0 and corrected `ctx.subscription` narrowing. Existing polling, draft/final delivery, topics, media/upload, retry, and connectivity behavior remains authoritative.
- Direct Fable planning remains unavailable because its OAuth is expired; this decision-complete plan uses the documented Minime fallback and is self-reviewed only for removals, simplification, and blockers.
